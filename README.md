# Full Senyum

Website for **Full Senyum**, cetak & souvenir untuk kebutuhan bisnis — a static, multi-page site
(Beranda, Karya + 6 detail pages, Tentang, Kontak) in the origostudio style: giant type, hairlines,
filmstrip work rows, label-left sections, navy / white / light grey. WhatsApp is the only contact
channel. Deploys to GitHub Pages at <https://full-senyum.github.io>.

Source of truth for decisions, copy and tokens: [`docs/build-spec.md`](docs/build-spec.md).
Open items for the owner: [`docs/handoff.md`](docs/handoff.md). Photo credits: [`CREDITS.md`](CREDITS.md).

## Run

Node 22 and npm.

```bash
npm install
npm run dev            # http://localhost:3000 (the workspace launch entry "fullsenyum" uses 3022)
npm run build          # static export into out/
npm run preview        # serve out/ on http://localhost:3023 (launch entry "fullsenyum-static")
```

Checks (all must pass before a deploy):

```bash
npm run typecheck      # next typegen && tsc --noEmit
npm run lint
npm run build
```

## Stack

- Next.js 16 App Router, TypeScript strict, `output: "export"`, `trailingSlash: true`, unoptimized images
- Tailwind CSS v4 (CSS-first tokens in `src/app/globals.css`)
- shadcn/ui v4 on Base UI (`button`, `accordion`, `sheet`, `separator`), restyled to the spec
- `motion` for section reveals, the showreel settle and the metric counters; CSS keyframes for the
  hero wordmark and the client marquee; everything respects `prefers-reduced-motion`
- Switzer (Fontshare, ITF Free Font License) self-hosted via `next/font/local` in `src/fonts/switzer/`
- Icons: `@tabler/icons-react`, stroke 1.5

## Editing content

- **Contact, address, WhatsApp greeting:** `src/data/site.ts`. `waLink()` builds every WhatsApp link;
  `waLink("Payung Custom")` appends the product to the greeting.
- **Product lines** (Karya list, detail pages, footer, product chips): `src/data/lines.ts`. The first
  photo id is the cover; ids must exist in `photos.json`.
- **Services / steps / FAQ / metrics:** the matching file in `src/data/`.
- Keep the ground rules from the spec: no prices, MOQs, lead times, years, ratings or testimonials;
  spelling "souvenir"; WhatsApp only.

## Generated assets

These files are produced by the asset pipelines and are consumed as-is (never hand-edited by the site
code). Regenerate them with the same shape and the site picks them up without code changes:

| File | Shape (see spec §6) | Notes |
|---|---|---|
| `src/data/photos.json` + `public/images/karya/` | `{ id, line, product, client, alt, width, height, sources[], lqip }` | client names are shown without branch suffixes (`KC …`) |
| `src/data/stock.json` + `public/images/stock/` | `{ id, alt, width, height, sources[], lqip, credit, placeholder }` | ids `home-showreel`, `about-print`, `about-smile`, `contact-parcel`; a missing id hides its section |
| `src/data/bento.json` + `public/media/bento/` | `{ id, kind, video?, poster?, image?, width, height, kicker, title }` | display order = file order; the first tile is the big one |
| `src/data/clients.json` + `public/clients/` | `{ name, slug, src, width, height, scale, fallbackText }` | first 10 → marquee row 1, the rest → row 2; `fallbackText: true` renders the name |
| `src/components/brand/logo-paths.ts` | `LogoArt { viewBox, width, height, letters[], smile }` | generated by `tools/logo/generate.mjs` |
| `src/app/icon.svg`, `favicon.ico`, `apple-icon.png`, `public/icon-*.png`, `brand/*.svg` | icons + logo exports | generated by `tools/logo/generate.mjs` |

Images are plain `<img srcset>` (static export); sizes come from the manifest, so always keep
`width`/`height` accurate.

### Logo and icons

The wordmark is Switzer Bold plus the smile arc, generated from the font file. To rebuild
`logo-paths.ts`, the favicons, the app icons and the `brand/` SVG exports (tooling stays out of
`package.json`):

```bash
mkdir -p /tmp/logo-tools && npm i --prefix /tmp/logo-tools opentype.js@1 @resvg/resvg-js@2
LOGO_TOOLS=/tmp/logo-tools node tools/logo/generate.mjs
```

## Design rules (short)

Switzer only, `letter-spacing: 0`, no uppercase, no monospace. Navy `#0D1B3E`, white, greys
(`grey-50`, `grey-100`, `line`, `muted`) — no other hues outside photos. Radius 0 everywhere except
pill buttons and chips. No shadows, no decorative gradients (image scrims only). One divider: the 1px
`line` hairline. Breakpoints: `md` 810px (tablet), `xl` 1440px (desktop), plus `sm` 640 / `lg` 1024 /
`2xl` 1536 — all in px (mixing units breaks Tailwind's variant order).

## Deploy (GitHub Pages)

The workflow `.github/workflows/deploy.yml` builds on every push to `main` (or manually) and publishes
`out/` with `actions/deploy-pages`. Nothing has been pushed yet. To go live:

1. Create the repository `full-senyum/full-senyum.github.io` (org site, so no `basePath`).
2. In the repo: **Settings → Pages → Source: GitHub Actions**.
3. Commit and push this folder to `main`:

   ```bash
   git add -A && git commit -m "Full Senyum website"
   git remote add origin git@github.com:full-senyum/full-senyum.github.io.git
   git push -u origin main
   ```

`public/.nojekyll` keeps GitHub from hiding the `_next/` folder; `out/404.html` is served for unknown
URLs.
